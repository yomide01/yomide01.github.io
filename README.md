# AAT Studio — Digital Media & Short-Form Production Platform

Official web portal, interactive short-form pacing workbench, OAuth 2.0 channel gateway, and legal documentation for **AAT Studio** ([https://yomide01.github.io](https://yomide01.github.io)).

## Portal Structure
- **[Studio Home & Pacing Workbench](https://yomide01.github.io/)** — Interactive vertical short-form pacing simulator, 9:16 HUD preview, and studio architecture overview.
- **[Creator Authentication Gateway](https://yomide01.github.io/callback)** — OAuth 2.0 redirect and session handshake verification portal.
- **[Privacy Policy](https://yomide01.github.io/privacy.html)** — Google API Services User Data Policy (Limited Use) & credential security disclosure.
- **[Terms of Service](https://yomide01.github.io/terms.html)** — Studio terms, editorial attribution standards, and YouTube Terms of Service compliance.
